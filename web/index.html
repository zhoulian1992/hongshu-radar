浏览器插件 / 书签推送

对应文章最后那段：在商品页点一下「加入监控队列」，把链接 POST 给本地服务；带上销量时按同一口径落快照。

curl -X POST http://127.0.0.1:8777/api/ingest \
  -H 'Content-Type: application/json' \
  -d '{"url":"商品链接","title":"名称","sold":"已售2210","price":9.9}'

只传 url = 加入队列；多传 sold = 顺手写一条快照。完整油猴脚本见 tools/加入监控队列.user.js。
